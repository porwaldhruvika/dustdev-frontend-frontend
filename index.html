An IDE that keeps working — even when the internet doesn't.

DustDev combines cloud devcontainers when you're online with OPFS + WebContainers offline. Run code, build projects, and use local AI assistants — all without losing work in rural Arizona.

Designed for rural communities

DustDev helps developers, students, and local organizations stay productive where connectivity is limited.

Resilient development

Seamless switching between cloud devcontainers when connected and local WebContainers + OPFS when offline so your environment never breaks.

Local AI assistants

AI tools that can run locally (on-device) when offline — code completion, refactors, and small models for common tasks.

Community-first

Resources and presets tailored to rural Arizona: low-bandwidth templates, offline learning modules, and community training guides.

Secure and private

Data stays in your browser when offline (OPFS), and cloud workspaces are ephemeral and encrypted when used.

How it works

  1. Online: Spin up cloud devcontainers — full compute in the cloud, synced to your account.
  2. Offline: DustDev uses OPFS and WebContainers to run and persist code locally inside the browser.
  3. AI anywhere: Lightweight models and inference run locally for common tasks; larger models can be used when online.
